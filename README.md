# Rastgele Atasözü Bozan Makinesi

## Bu Ne?

Bu, dünyanın **en ciddi** atasözü bozma makinesidir. Evet, ciddi. Gerçekten çalışıyor. İnanmıyorsanız çalıştırın.

Atasözleri asırlardır bize yol gösterdi. Artık yol göstermesinler. Bu makine onları bozar, ters çevirir, kelimelerini değiştirir ve size "acaba doğru muydu?" diye sordurur.

## Nasıl Çalıştırılır?

Python 3 yüklü olmalı (eğer yoksa bu repo sizi yargılar).

```bash
python bozucu.py
```

Çıktı olarak 5 tane bozulmuş atasözü verir. Her seferinde farklı. Çünkü rastgele. Çünkü ciddi.

## Özellikler

- Gerçek atasözlerini bozar
- Ters çevirir
- Kelimeleri değiştirir
- Büyük harfle bağırır
- Sonuna "yoksa öyle miydi?" ekler
- Hiçbir şey yapmaz gibi görünür ama yapar

## Uyarı

Bu makine atasözlerini bozar. Eğer atasözlerinize bağlıysanız, çalıştırmayın. Yoksa bir daha "damlaya damlaya göl olur" diyemezsiniz. Çünkü göl olmaz artık.
